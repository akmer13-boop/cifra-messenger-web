# CIFRA Messenger Web — версия 11

Адаптивный интерактивный iOS-веб-прототип CIFRA Messenger. Этот пакет
подготовлен для отдельного GitHub-репозитория `cifra-messenger-web` и дальнейшего
подключения к CIFRA Gateway, Tinode и корпоративному WebSocket.

## Что уже работает

- чаты, беседы, поиск, категории, архив и удалённые чаты;
- свайпы 20% / 33% / 40%, закрепление до трёх чатов;
- создание группы, выбор и корректный подсчёт участников;
- профили администратора и сотрудника, каталог организации и аудит;
- групповой звонок как UI-сценарий;
- медиа, файлы, голосовые сообщения и четыре темы;
- iPhone safe-area, адаптивность и доступные названия элементов;
- контрактные тесты интерфейса.

## Важное ограничение текущей версии

Данные пока демонстрационные и находятся в `app/page.tsx`. Изменения живут в
памяти браузера, а тема и режим уведомлений — в `localStorage`. Реальные
пользователи, сообщения, роли, медиа и звонки ещё не подключены к серверу.

## Быстрый запуск

Требуется Node.js 22 или 24.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`.

Полная проверка:

```bash
npm run check
```

## Режимы данных

По умолчанию:

```env
NEXT_PUBLIC_DATA_MODE=mock
```

Перед серверной интеграцией скопируйте `.env.example` в `.env.local`, заполните
адреса тестового контура и только после подключения адаптеров переключите:

```env
NEXT_PUBLIC_DATA_MODE=api
```

Не помещайте JWT, пароли, ключи БД и другие секреты в `NEXT_PUBLIC_*`.

## Рекомендуемая модель репозиториев

- `cifra-messenger-web` — этот frontend;
- `cifra-messenger-backend` — существующий модульный монолит;
- на Amvera Gateway, Worker, Tinode, PostgreSQL и frontend запускаются
  отдельными приложениями/ресурсами.

Физически смешивать frontend и backend в одной папке не требуется: они
соединяются через REST API и WebSocket.
